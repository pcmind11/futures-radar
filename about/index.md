# 소개

**나만의 미래전략연구소**는 3개월 후, 3년 후, 10년 후의 미래를 더 정확하게 이해하기 위해 미래학자·연구기관·언론의 전망을 꾸준히 모으고 비교하며, 나만의 미래관을 쌓아가는 개인 연구 사이트입니다.

## 운영 방식

- **수집**: 매일 한국시간 오전 7시에 구글 뉴스 검색(RSS)으로 한국어·영어 헤드라인을 모읍니다. 검색어는 AI·기술, 인구·고령화·사회, 에너지·기후·환경·자원, 경제·금융·투자, 미래학자·기관 분야별로 정해 두었습니다.
- **요약·번역**: AI(Google Gemini 무료 API)가 고른 항목을 한국어로 번역하고 한 문장으로 요약합니다.
- **주간 리포트**: 매주 일요일에 한 주의 신호를 3개월·3년·10년으로 나누고, 낙관·비관 관점을 나란히 정리합니다.
- **한계**: 모든 것을 실시간으로 자동 수집하는 것이 아닙니다. 하루 한 번, 정해 둔 검색어에 걸린 헤드라인만 다룹니다. 요약은 제목만 보고 만든 것이라 틀리거나 빠진 내용이 있을 수 있습니다.

## 표시 읽는 법

| 표시 | 의미 |
|---|---|
| 사실 | 확인된 데이터나 사건을 전하는 내용 |
| 추정(전망) | 앞으로의 일을 예측하는 내용 |
| 전문가 의견 | 특정 전문가의 견해 |
| 근거 강도 낮음 | 제목만 보고 만든 요약이라 근거가 약하다는 뜻. 원문으로 확인하세요 |
| 3개월 / 3년 / 10년 | 그 내용이 관련된 미래 시점 (AI가 분류하며 '시점 불명'도 있습니다) |

## 안내

이 사이트의 내용은 정보 제공과 학습을 위한 것이며 투자 권유가 아닙니다. 확률과 전망은 객관적으로 측정된 수치가 아니라 분석에 바탕을 둔 주관적 판단입니다.
